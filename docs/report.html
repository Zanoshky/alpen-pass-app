Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and answers.
  • One problem per report makes it faster to fix.

What helps

For a wrong question
Your federal state, the German question as the app shows it, and the source line under it (booklet and page). If you know the question id, like wien.012, add it. Say what is wrong and where the booklet or the law says otherwise.
App version
Settings, About Alpen Pass.
Phone model and Android version
Android settings, About phone.
Screen and steps
Which screen, and what you did, one step per line, so we can do the same.
Expected and actual
What you thought would happen, and what happened.
A picture
A screenshot of a study page, or a short description. Practice and the mock exam are kept out of screenshots, so copy the question text instead.

Issues on GitHub are public. Do not write your name, address, case number or anything else private in a report, and check a screenshot before you attach it.

Other ways

Prefer not to use GitHub? Write to support@zanoski.com (write an email).
